Final Reflection

AI can support development, but understanding and verification still depend on human judgement.

AI tools helped me generate ideas, understand code, debug problems, and improve documentation. However, I learned that AI-generated results should not be trusted blindly.

I verified AI-generated results by reading the code, running test cases, checking terminal output, reviewing GitHub Actions results, and comparing the output with project requirements.

My biggest growth from this course is learning how to organize projects clearly, record development history, and explain technical work with evidence.
